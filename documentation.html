Introduction

The Quokka API에 오신 것을 환영합니다! 이 API를 사용하면 여러분의 웹사이트나 앱에 "세상에서 가장 행복한 동물" 쿼카의 사진을 쉽게 추가할 수 있습니다.

우리의 API는 RESTful 구조를 따르며, JSON 형식으로 데이터를 반환합니다. 지금 바로 무료로 시작해보세요!

Authentication

일부 엔드포인트는 API Key가 필요합니다. 하지만 GET /images/search와 같은 기본 기능은 인증 없이도 바로 사용할 수 있습니다. 

x-api-key: YOUR_API_KEY_HERE

Search Images

랜덤한 쿼카 이미지를 가져오는 가장 기본적인 엔드포인트입니다.

GET https://api.thequokka.com/v1/images/search

Parameters

Parameter Type Description
limit Number 반환할 이미지 개수 (기본값: 1)
size String 이미지 크기 (small, med, full)

Example Response

[
  {
    "id": "q_001",
    "url": "https://cdn.thequokka.com/images/q_001.jpg",
    "width": 800,
    "height": 600
  }
]

List Breeds (Macropodidae)

쿼카는 캥거루, 왈라비와 같은 유대류(Macropodidae, 캥거루과)에 속합니다. 이 엔드포인트는 쿼카 API에서 지원하는 관련 동물 친구들의 목록을 반환합니다.

GET https://api.thequokka.com/v1/breeds

Example Response

[
  {
    "id": "br_quokka",
    "name": "Quokka",
    "family": "Macropodidae",
    "habitat": "Rottnest Island, Australia"
  },
  {
    "id": "br_kangaroo",
    "name": "Kangaroo",
    "family": "Macropodidae",
    "habitat": "Australia mainland"
  },
  {
    "id": "br_wallaby",
    "name": "Wallaby",
    "family": "Macropodidae",
    "habitat": "Australia & New Guinea"
  }
]

Analyze Happiness (AI) NEW

The Quokka API의 최첨단 AI 알고리즘이 제공된 사진 속 쿼카의 표정을 분석하여 미소 지수(Happiness Index)를 측정합니다.

POST https://api.thequokka.com/v1/images/{id}/analyze
